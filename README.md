# AETHER-1

AETHER-1 is an open-source experimental language model built from scratch for learning and research.

The project focuses on understanding how language models work internally, from tokenization and datasets to Transformer architecture, training, generation, and eventually Android deployment.

## Goals

- Build a language model from scratch
- Understand Transformer architecture
- Train using custom datasets
- Run inference on Android
- Improve the model with larger datasets and better hardware
- Keep the project open-source
