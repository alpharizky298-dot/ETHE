AETHER adalah proyek kecerdasan buatan open source yang dibuat untuk mempelajari cara kerja model bahasa.

Deep learning menggunakan neural network dengan banyak lapisan untuk mempelajari representasi data yang kompleks.

Neural network terdiri dari berbagai parameter yang dapat disesuaikan selama proses training.

Model bahasa mempelajari hubungan antara token dalam sebuah rangkaian teks.

Training adalah proses mengubah parameter model agar prediksi model menjadi semakin baik.

Pada setiap proses training, model menerima input dan mencoba memprediksi target berikutnya.

Loss digunakan untuk mengukur seberapa jauh prediksi model dari target yang benar.

Optimizer digunakan untuk memperbarui parameter berdasarkan nilai loss.

Gradient menunjukkan arah perubahan parameter yang dapat digunakan untuk mengurangi loss.

Data training digunakan untuk memperbarui parameter model.

Data validation digunakan untuk mengukur kemampuan model pada data yang tidak digunakan untuk memperbarui parameter.

Overfitting terjadi ketika model terlalu menghafal data training dan kurang mampu melakukan generalisasi.

Underfitting terjadi ketika model belum cukup belajar dari data.

Transformer adalah arsitektur neural network yang banyak digunakan dalam model bahasa modern.

Transformer menggunakan mekanisme attention untuk mempelajari hubungan antar bagian dalam sequence.

Self attention memungkinkan sebuah token memperhatikan token lain dalam konteks yang sama.

Context adalah bagian teks yang tersedia bagi model ketika membuat prediksi.

Layer normalization membantu menjaga proses pembelajaran neural network tetap stabil.

Feed forward network memproses representasi setiap token setelah mekanisme attention.

Activation function memungkinkan neural network mempelajari hubungan yang tidak sederhana.

GELU adalah salah satu fungsi aktivasi yang sering digunakan dalam transformer.

Parameter model adalah nilai yang dipelajari selama training.

Inference adalah proses menggunakan model yang telah dilatih untuk menghasilkan prediksi.
